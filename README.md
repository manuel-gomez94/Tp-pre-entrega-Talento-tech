# Yami-no Card

Tienda online de cartas, booster boxes y accesorios de **Yu-Gi-Oh! TCG**.
Pre-Entrega de Proyecto del curso Front-End JS (Talento Tech).

## Estructura

```
/
├── index.html
├── README.md
├── css/
│   └── styles.css
├── img/
└── pages/
    └── contacto.html
```

## Qué incluye

- HTML semántico (`header`, `nav`, `main`, `section`, `article`, `footer`).
- CSS externo en `css/styles.css` con Google Fonts (Poppins) y fondo con degradé.
- Productos con cards responsivas usando **Flexbox**.
- Reseñas con **Grid**.
- Página de contacto con formulario (Formspree) y **Media Queries**.
- Lista de navegación interna (anclas) en el inicio.
